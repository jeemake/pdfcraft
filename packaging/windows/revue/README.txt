Revue PDF K&D - setup
=====================

Install
  Double-click Install.cmd. It installs for this Windows account and needs no
  administrator rights. To install for every account on this PC, open PowerShell
  here and run:  .\Install.cmd -AllUsers

  Then right-click any PDF > Open with > Revue PDF K&D.
  To always open PDFs with it: right-click a PDF > Open with > Choose another app
  > Revue PDF K&D, and tick "Always".

Uninstall
  Settings > Apps > Revue PDF K&D > Uninstall, or double-click Uninstall.cmd.
  Your PDFs and settings are kept.

If Windows shows "Windows protected your PC", click More info > Run anyway:
the setup is not code-signed.
